➕ Add a new tool

Every tool is just a folder. No build step, no restart for UI changes.

1. Copy the template

Duplicate the folder tools/_template and rename it, e.g. tools/my-thing.

Folders that start with _ or . are hidden from the dashboard (that's why the template doesn't show up).

2. Edit tool.json

{
  "name": "My Thing",
  "description": "What it does.",
  "icon": "✨",
  "color": "#10b981",
  "tags": "utility",
  "order": 10
}

The folder name becomes the tool's id and its URL/API prefix.

3. Build the UI in ui.html

It's a normal standalone web page. Link /tool-kit.css for the shared look. Write any HTML/CSS/JS you want — it runs isolated in its own frame.

4. (Optional) Add a backend in api.js

Need server-side logic, file access, or to call an API with a secret key? Add api.js. Your UI calls it at:

fetch("/api/my-thing/whatever", { method: "POST", ... })

See tools/_template/api.js for the handler shape. Edit it freely — it reloads on each request, no restart needed.

5. Refresh

Reload the dashboard. Your tool appears automatically in the sidebar and on the home screen. New tool folders are picked up without restarting the server.

Tip: ask Claude Code to "add a <whatever> tool to my Tool Hub" and it can scaffold the whole folder for you.
